# 🤖 Prototipo Robótico Cybertruck Educativo

Recursos educativos del prototipo robótico Cybertruck controlado mediante un **ESP32 por Bluetooth**, con una aplicación desarrollada en **MIT App Inventor**.

## 📌 Descripción

Este repositorio hace parte del proyecto de desarrollo de prototipos robóticos educativos y reúne los recursos necesarios para conocer, programar y utilizar el prototipo Cybertruck.

El sistema integra elementos de **robótica, electrónica y programación**, permitiendo controlar el movimiento del prototipo desde un dispositivo móvil mediante comunicación Bluetooth.

## 🎯 Objetivo

Facilitar el aprendizaje de conceptos básicos de robótica y programación mediante un prototipo educativo que permita explorar la relación entre hardware, software y comunicación inalámbrica.

## ⚙️ Tecnologías y herramientas

- **ESP32 DevKit V1** — Unidad de control del prototipo.
- **Bluetooth** — Comunicación inalámbrica entre el teléfono y el ESP32.
- **Arduino IDE** — Programación del ESP32.
- **MIT App Inventor** — Desarrollo de la aplicación móvil de control.
- **Fusion 360** — Diseño y modelado del prototipo.
- **Impresión 3D** — Fabricación de las piezas del prototipo.
